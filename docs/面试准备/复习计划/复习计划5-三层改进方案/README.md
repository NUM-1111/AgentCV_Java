## 🔄 面试后恢复节奏（操作手册）

> 每次面试后按此流程操作，不要跳步。

### 面试后24小时内
1. **当天立刻**（30min）：录音转文字 + 100字即时感受
2. **24h内**（1-2h）：按模板出深度复盘报告

### 面试间修复窗口
- 两场面试间隔 ≥ 5天
- 投简历不减速，面试排期选最晚
- 面完→复盘→修复→验证（模拟面试验收）→下一场

### 超纲应答兜底公式
> "这个我确实没深入了解过，但我可以试着分析——[给思路]。如果实际做我会去看[具体资料]。"

**绝不做**：沉默超过10秒、主动说"这方面接触的没有"、反问面试官"您能跟我说一下吗"
