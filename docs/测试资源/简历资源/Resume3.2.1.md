### 项目一：AgentCV（基于大模型的求职场景智能助手）

**岗位**：核心开发者 | 技术栈：Java 17, Spring Boot 3.2, LangChain4j 0.36, Spring AOP, Jackson, Jakarta Validation

#### 项目简介
通用大模型改写简历时会凭空虚构技术栈与量化数据。针对这一核心痛点，设计并实现了多维评分驱动的双Agent事实对齐架构，覆盖JD解析、人岗匹配评估、简历改写、事实核查的完整链路。

#### 技术亮点

1. **多维评分驱动的双Agent改写体系**：设计了多维评分驱动的双Agent管线——评分引擎从匹配度、内容质量、格式规范等维度量化简历质量；Writer以原文为事实边界做STAR法则改写；Critic基于分级违规检测与一票否决制核查事实准确性。通过Function Calling为Critic注册事实核查工具，使其在检测到可疑声明时自主调用工具做精确比对。违规召回验证100%。

2. **简历结构感知的局部改写管线**：自动识别简历中个人信息、教育背景、技能列表、项目经历等结构区域，仅对项目经历段落走改写+审查流程，其余部分原样保留后回填拼接，用户无需手动截取粘贴。

3. **大模型结构化输出多层防御体系**：面向大模型JSON输出的字段缺失、键名漂移、类型错误等问题，设计"JSON提取→字段名归一化→宽容反序列化→业务规则校验"四层解析Pipeline，逐层兜底，格式异常最终拦截率100%。

4. **上下文窗口治理与Token预估**：基于标题关键词正则裁剪将输入压缩至原始约35%，配合本地Token预估算与超限拦截，由自动化校准测试持续验证约束边界，单次调用Token消耗显著降低。

5. **SSE阶段级进度推送与全链路日志**：管线耗时60-120s，通过SSE按评分/改写/审查三阶段推送进度，前端以进度条展示当前阶段，完成后一次性渲染完整结果，支持复制+导出MD。配合Spring AOP双切面与MDC traceId实现全链路日志追踪。
