## 面试总结

**整体表现：** 扎实，有工程思维。

**做得好的地方：**

- 问题定义清晰，能区分"格式问题"和"字段漂移"两个维度，没有把它们混为一谈
- 理解了 Prompt 约束的局限性，知道后端防线比模型约束更可靠
- 能识别自己方案的不足，比如异常分类不够细、未知别名没有处理，没有回避
- 对 `JacksonConfig` 和 `FacadeService` 的职责边界，经过代码确认后能说清楚

**可以加强的地方：**

1. **异常分类**：解析失败 vs 字段校验失败，应该返回不同的错误码和错误结构，这是生产级接口的基本要求
2. **未知字段漂移的兜底**：目前是 `FAIL_ON_UNKNOWN_PROPERTIES = false` 静默丢弃，这在某些场景下等于把问题藏起来了，可以考虑记录告警日志，至少让开发者感知到
3. **`extractJsonObject` 的边界**：当前用首个 `{` 到最后一个 `}` 截取，如果模型输出里有嵌套的 JSON 字符串或者多个 JSON 对象，这个逻辑会有误判，值得加一个单测覆盖这类边界 case

**一句话评价：** 这套方案从"能跑"到"可控"的跨越做到了，下一步是从"可控"到"可观测"——让每一层的失败都有迹可查、有码可辨。
