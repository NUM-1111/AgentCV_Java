## 45 秒脱稿自我介绍（照着图讲）

> "这是一个 Agent 简历优化系统，全链路分四层。
>
> **输入层**——TextTrimmer 把 JD 和简历噪声过滤掉，保留核心段落，裁剪到 8000 字。TokenEstimator 做保守估算，超过 1 万 token 直接拦截。
>
> **核心层**——Actor-Critic 双 Agent 循环，Writer 按 JD 改写、Critic 做事实核查输出四类违规报告，Coordinator 根据 maxSeverity 做 ≤2 通过/≥3 重写的决策，最多 3 轮。
>
> **输出层**——四层防御 Pipeline 处理 LLM JSON 输出不稳定问题，从剥 Markdown 到字段校验逐层兜底。
>
> **横向**——AOP 双切面加 MDC traceId 做全链路追踪。整个项目用 Spring Boot + LangChain4j + DeepSeek V4-Flash 实现。"
