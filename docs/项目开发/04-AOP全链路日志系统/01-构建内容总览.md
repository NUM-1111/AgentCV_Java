# 01 — 构建内容总览

本次为 AgentCV_Java 从零搭建了 AOP 全链路日志系统，共新增/修改 6 个文件。

---

## 新增文件结构

```
src/main/
├── java/com/jobagent/
│   ├── aspect/
│   │   ├── WebLogAspect.java       ← HTTP 层切面（新增）
│   │   └── AiCallLogAspect.java    ← AI 调用层切面（新增）
│   └── filter/
│       └── TraceIdFilter.java      ← 请求追踪 ID 注入（新增）
└── resources/
    ├── logback-spring.xml          ← 日志格式配置（新增）
    └── application.yml             ← 补充日志级别（修改）
pom.xml                             ← 添加 AOP 依赖（修改）
```

---

## 各文件做了什么

### `pom.xml` — 添加 AOP 依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aop</artifactId>
</dependency>
```

Spring Boot 的 AOP starter 会自动引入 AspectJ 织入器，让 `@Aspect` 注解生效。没有这个依赖，切面类只是普通 Bean，不会拦截任何方法。

---

### `logback-spring.xml` — 统一日志格式

Spring Boot 优先加载 `logback-spring.xml`（而非 `logback.xml`），支持 `<springProfile>` 环境隔离。

核心格式：
```
12:34:56.001  INFO [a1b2c3d4] c.j.aspect.AiCallLogAspect : [AI-CALL] evaluate | ...
```

字段说明：
| 字段 | 含义 |
|------|------|
| `12:34:56.001` | 时间，精确到毫秒 |
| `INFO` | 日志级别 |
| `[a1b2c3d4]` | traceId，由 TraceIdFilter 注入 MDC |
| `c.j.aspect.AiCallLogAspect` | 类名（缩写，最长40字符） |
| `[AI-CALL] evaluate \| ...` | 业务日志消息 |

---

### `TraceIdFilter.java` — 请求追踪 ID

每个 HTTP 请求进来时，生成一个 8 位短 UUID 作为 `traceId`，写入 SLF4J 的 MDC（线程本地存储）。

```java
String traceId = UUID.randomUUID().toString().replace("-", "").substring(0, 8);
MDC.put("traceId", traceId);
response.setHeader("X-Trace-Id", traceId);  // 也写入响应头，方便前端排查
```

请求结束后在 `finally` 块清理 MDC，防止线程池复用时 traceId 串号。

效果：同一个请求产生的所有日志行都带相同的 `[a1b2c3d4]`，出问题时用 `grep a1b2c3d4` 一行命令就能过滤出完整链路。

---

### `WebLogAspect.java` — HTTP 层切面

切点：所有 `@RestController` 类的所有方法。

```java
@Pointcut("@within(org.springframework.web.bind.annotation.RestController)")
public void restControllerMethods() {}
```

记录内容：
- HTTP 方法（GET/POST）
- 请求 URI
- 入参 JSON 摘要（超 200 字符截断）
- 总耗时（毫秒）
- 成功/异常状态

成功日志示例：
```
[WEB] POST /api/v1/match/evaluate | args=[{"jdText":"Java工程师..."}] | cost=3521ms | status=OK
```

异常日志示例：
```
[WEB] POST /api/v1/match/evaluate | args=[{"jdText":""}] | cost=2ms | ERROR=IllegalArgumentException: jdText 不能为空
```

异常会被重新抛出，让 `GlobalExceptionHandler` 继续处理，切面不吞异常。

---

### `AiCallLogAspect.java` — AI 调用层切面

切点：精准切入 `MatchEvaluationFacadeService.evaluate()` 方法。

```java
@Pointcut("execution(* com.jobagent.service.MatchEvaluationFacadeService.evaluate(..))")
public void aiEvaluateMethod() {}
```

记录内容：
- JD 字符数、简历字符数（不打印全文，防止日志爆炸）
- 整个 AI 调用链路耗时（秒级）
- 成功时：`matchScore`、`matchedSkills` 数量、`missingSkills` 数量
- 失败时：异常类型 + 消息摘要（150字截断）

成功日志示例：
```
[AI-CALL] evaluate | jdLen=800 resumeLen=1200 | cost=3456ms | score=85 matchedSkills=5 missingSkills=2
```

失败日志示例：
```
[AI-CALL] evaluate | jdLen=800 resumeLen=1200 | cost=1200ms | ERROR=ContextWindowExceededException: 估算token=12000超过上限10000
```

## 一次完整请求的日志链路

发送 `POST /api/v1/match/evaluate`，控制台输出顺序：

```
12:34:56.001  INFO [a1b2c3d4] c.j.filter.TraceIdFilter           : (静默注入 traceId，无日志输出)
12:34:56.002 DEBUG [a1b2c3d4] c.j.s.MatchEvaluationFacadeService : 裁剪前 JD=1200字 简历=2000字，裁剪后 JD=800字 简历=1200字
12:34:59.458  INFO [a1b2c3d4] c.j.aspect.AiCallLogAspect         : [AI-CALL] evaluate | jdLen=800 resumeLen=1200 | cost=3456ms | score=85 matchedSkills=5 missingSkills=2
12:34:59.459  INFO [a1b2c3d4] c.j.aspect.WebLogAspect            : [WEB] POST /api/v1/match/evaluate | args=[{...}] | cost=3521ms | status=OK
```

每行都带同一个 `[a1b2c3d4]`，可以精确过滤出这一次请求的完整链路。

## 优化效果对比

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 请求追踪 | 无，出问题靠猜 | 每个请求有唯一 traceId |
| HTTP 层日志 | 无 | 接口、入参摘要、耗时、状态 |
| AI 调用日志 | 无结构化记录 | 耗时、评分、技能数量、异常类型 |
| 日志格式 | 默认 Spring Boot 格式 | 带 traceId 的彩色结构化格式 |
| 侵入性 | — | 零侵入，Controller/Service 代码无需修改 |
