## 核心结论

当前 `MatchEvaluationFacadeService` 对输入长度完全无感知，`jdText` 和 `resumeText` 原样透传给 DeepSeek API，没有：
- token 预估
- 业务层裁剪
- 主动拦截
- 超长错误提示
