# TextTrimmer 稳健性改造报告

**日期**：2026-04-13  
**改造文件**：`src/main/java/com/jobagent/util/TextTrimmer.java`  
**测试文件**：`src/test/java/com/jobagent/util/TextTrimmerTest.java`  
**测试结果**：31 / 31 通过，耗时 0.116s

---

## 一、原代码缺陷清单

| # | 缺陷 | 影响 |
|---|------|------|
| 1 | 标题判定只看行长度，内容里的短句被误判为新标题 | 段落被错误截断，内容丢失 |
| 2 | 找不到目标模块时直接硬截断原始文本 | 垃圾内容（福利/公司介绍）被保留，有效内容被挤掉 |
| 3 | 不支持"标题+内容同行"格式（如 `岗位职责：负责开发...`） | 同行内容全部丢失 |
| 4 | 截断直接按字符切，经常切在半句话中间 | 语义破碎，AI 读到残句 |
| 5 | 对空行、多余空格、序号标题（`1.`、`一、`）兼容性差 | 真实 JD/简历经常识别不到 |
| 6 | 关键词覆盖不足（缺少"工作任务"、"任职资格"、"职业经历"等） | 常见格式无法命中 |

## 二、改造方案与实现

### 2.1 修复标题误判

**原逻辑**：短行（≤20字）且以中文/英文开头 → 判定为标题。  
**新逻辑**：`isHeading()` 严格双重判定：

```java
static boolean isHeading(String line) {
    if (line == null || line.isBlank()) return false;
    // 含句子标点的一定不是标题
    if (line.matches(".*[。，；！？…].*")) return false;
    return HEADING_PATTERN.matcher(line).matches();
}
```

- 含 `。，；！？…` 的行直接排除，不再误判"代码质量高。"为标题
- `HEADING_PATTERN` 要求主体长度 2-20 字，可选序号前缀（`1.`、`一、`、`（一）`）

### 2.2 支持"标题+内容同行"

**原逻辑**：`targetPattern` 要求关键词独占一行，同行内容被丢弃。  
**新逻辑**：关键词只需出现在行首，整行（含后续内容）都纳入段落：

```java
Pattern targetPattern = Pattern.compile(
    "(?i)^(?:[\\d一二三四五六七八九十]+[.、．]|...)?\\s*(" + combined + ")[：:：]?"
);
// 匹配后：sb.append(line)  ← 整行纳入，不丢内容
```

### 2.3 关键词扩充

| 类别 | 新增关键词 |
|------|-----------|
| JD 职责 | `工作任务`、`主要任务` |
| JD 要求 | `任职资格`、`必备条件`、`专业要求` |
| 简历 | `职业经历` |

### 2.4 智能截断

**原逻辑**：`hardTruncate()` 直接按字符切。  
**新逻辑**：`smartTruncate()` 在 `[70%limit, limit]` 窗口内向前找最近的句子结束符：

```java
static String smartTruncate(String text, int limit) {
    if (text.length() <= limit) return text;
    int searchFrom = (int) (limit * 0.7);
    for (int k = limit - 1; k >= searchFrom; k--) {
        char c = text.charAt(k);
        if (c == '。' || c == '！' || c == '？' || c == '\n' || c == '!' || c == '?') {
            return text.substring(0, k + 1).stripTrailing() + "\n…[已截断]";
        }
    }
    return hardTruncate(text, limit);  // 实在找不到再硬切
}
```

### 2.5 兜底策略

**原逻辑**：找不到目标模块 → `hardTruncate(原文, 4000)`，垃圾内容照单全收。  
**新逻辑**：`fallbackTrim()` 先过滤垃圾行，再截断：

```java
static String fallbackTrim(String text, int limit) {
    // 过滤：福利/五险/公积金/公司介绍/电话/邮箱/地址...
    // 过滤：纯标题行且长度 ≤ 6 字（无实质内容）
    // 若过滤后内容 < 50 字，退回原文（防止过度过滤）
    return smartTruncate(filtered, limit);
}
```

### 2.6 格式清洗

新增 `cleanText()`，在所有处理前执行：

```java
static String cleanText(String text) {
    String s = text.replace("\r\n", "\n").replace("\r", "\n");  // 统一换行符（兼容 CRLF）
    s = s.replaceAll("[ \t]{2,}", " ");                          // 合并连续空格/Tab
    s = s.replaceAll("\n{3,}", "\n\n");                          // 合并超过2个连续空行
    return s.trim();
}
```
